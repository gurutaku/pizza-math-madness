# Pizza Math Quest

A self-contained, Grade 4 math game with two mini games, designed for desktop, phones, and tablets.

## Mini games

- **Pizza Factory:** Drag the shopping cart to catch two falling pizza stacks whose values add to the order. Stack speed increases as successful rounds accumulate. Distractor stacks can be ignored; an incomplete order costs one shield when the round runs out.
- **Pizza Delivery:** Each of two side-by-side rows has the same number of stacks, with each stack showing how many pizzas it contains. Work out the multiplication total and drag the truck under the row that matches the pickup order before the release timer runs out. The timer gets shorter after each successful delivery.

## Controls

- Touch or mouse: drag the cart/truck left and right.
- Desktop: use the left and right arrow keys.
- Sound effects can be toggled in the top bar.

## Publish on GitHub Pages

Upload `index.html` to a folder in your GitHub Pages repository, such as `pizza-math-quest/`. Open the folder's `index.html` or its published URL. No libraries, remote images, or external data files are required.
